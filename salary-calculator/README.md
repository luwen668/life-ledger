# 💰 工资个税计算器 · 五险一金各地版

打工人刚需工具：2025 年度十城五险一金数据 + 个税累计预扣计算，支持年终奖计税方式对比、税后反推税前。

## 功能

| 功能 | 说明 |
|---|---|
| 工资计算 | 按**累计预扣法**逐月计算全年 12 个月个税（前低后高是正常现象） |
| 十城数据 | 北京、上海、广州、深圳、杭州、成都、武汉、南京、重庆、西安（2025 年度口径） |
| 年终奖对比 | 单独计税（政策延续至 2027 年底）vs 并入综合所得，自动推荐更省方案 |
| 税后反推 | 输入期望到手工资，二分查找反推税前月薪 |
| 专项附加扣除 | 子女教育 / 婴幼儿 / 赡养老人 / 房贷 / 房租 / 继续教育 |
| 高级参数 | 自定义社保基数、公积金基数（应对按基本工资缴纳等情况） |
| 城市特例 | 深圳深户养老 17%、成都医保固定基数 7646、上海公积金上限 7% 等 |

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 计算引擎测试

```bash
node test.js   # 24 个单元测试（含年终奖跳档陷阱、社保封顶、反推回归）
```

引擎与页面分离：`calc.js` 是纯函数模块，Node 可直接引入测试。

## 文件结构

```
index.html    页面骨架（四个标签页）
style.css     科技感深色主题
data.js       十城 2025 年度五险一金数据 + 税率表
calc.js       纯计算引擎（五险一金 / 累计预扣 / 年终奖 / 反推）
app.js        界面交互与渲染
test.js       单元测试
```

## ⚠️ 数据说明

- 数据为 **2025 年度**公开文件口径，每年约 7 月各地会调整基数
- 工伤费率按行业浮动，统一按 0.4%（上海 0.2%）估算
- 成都医保基数、南京医保单位比例等为特殊/估算口径，见页面各城备注
- **计算结果仅供参考**，实际以当地人社局 / 公积金中心 / 税务机关口径为准

## 更新某地数据

直接编辑 `data.js` 中对应城市对象即可，字段含义见文件内注释。更新后建议跑一遍 `node test.js`。
