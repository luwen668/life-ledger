# 人生账单 · Life Ledger

> 输入几个真实数字，生成一张值得截图分享的人生账单。

纯静态单页应用，零构建、零后端——所有计算均在浏览器本地完成，不收集任何数据。

**在线体验**：https://luwen668.github.io/life-ledger/

## 三笔账

| 幕 | 计算器 | 输出 |
|----|--------|------|
| 01 · 时间余额 ⏳ | 出生年月 | 已活天数、52×80 人生格子图、剩余时间、具象化类比 |
| 02 · 工资人生 💰 | 月薪 / 年限 / 周工时 | 总收入、真实时薪（含通勤折算）、价格带分层换算 |
| 03 · 房贷真相 🏠 | 贷款额 / 利率 / 年限 / 已还期数 | 月供、利息本金比例、总利息、提前还款对比 |

每一幕以 GSAP Scrollytelling 滚动叙事展开，结尾生成 1080×1350 杂志风卡片（PNG 下载，小红书/朋友圈直出）。

## 特性

- **沉浸滚动叙事**：数字 count-up 落定、格子图逐行点亮、图表随滚动生长
- **URL 分享**：输入编码进 hash（如 `#/time/1995-03`、`#/salary/10000-5-40`、`#/loan/100-3.6-30-5-0-20`），打开链接即复现结果
- **三张系列卡片**：№.01/02/03 各配专属版式、印章与侧注
- **跨幕联动**：先算工资，房贷幕会告诉你"省下的利息 = X 年工资"
- **无障碍**：`prefers-reduced-motion` 降级为静态终态，数字写入 aria-label

## 技术

单文件 `index.html`：原生 HTML/CSS/JS + GSAP 3（ScrollTrigger）+ Canvas（格子图与卡片绘制），Fraunces + Inter 字体，部署于 GitHub Pages。

## 本地运行

直接双击 `index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
